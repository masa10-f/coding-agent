# FL-006: Mandatory Removable-Paragraph Search

## Category
Review Discipline

## Description
For each section reviewed, name at least one paragraph whose removal leaves the argument intact, or state explicitly that none exists and why.

## Why It Matters
- Flow reviews drift into adding transitions, which lengthens the text while claiming to improve it
- Sections that grew by insertion almost always carry a paragraph that only restates its neighbors
- Removing one paragraph often repairs a handoff that no transition sentence could

## Correct Approach
- Test each paragraph by deleting it and re-reading the surrounding claims
- Nominate the one whose removal changes nothing, and say what, if anything, must move elsewhere
- If nothing is removable, state per paragraph what the argument loses without it

## Examples

### Weak
```text
The section reads well. Adding a transition before P4 would improve the flow.
```

### Strong
```text
Removable: P6. It restates P3's claim with different examples and adds no new
step. Deleting it connects P5 directly to P7, which removes the need for the
transition currently at the start of P7.
```

### Strong (nothing removable)
```text
No removable paragraph.
P1 states the question, P2 gives the measurement, P3 rules out the alternative
explanation, P4 states the conclusion. Removing any one leaves a gap.
```

## Review Guidance
A paragraph that is merely short or simple is not removable on those grounds. The test is whether the argument still holds without it.
