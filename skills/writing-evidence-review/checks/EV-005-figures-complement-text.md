# EV-005: Figures and Tables Complement the Text

## Category
Artifacts

## Description
The body text should state what a figure or table means, not transcribe it, and must not contradict it.

## Why It Matters
- Transcribing a table into prose doubles the length and adds nothing
- Contradictions between a number in the text and the same number in a table destroy trust in every other number
- Figures that no sentence refers to are usually leftovers from an earlier draft

## Correct Approach
- In the text, state the takeaway and point to the artifact: what to look at and what it shows
- Verify every number quoted in the text against the artifact it comes from
- Confirm each figure and table is referenced at least once and that the reference matches its content
- Ensure the caption is self-contained: readable without the body text

## Examples

### Weak
```text
Table 2 shows the results. Method A achieved 0.71, Method B achieved 0.74,
Method C achieved 0.69, and Method D achieved 0.81 on the first dataset, while on
the second dataset Method A achieved 0.65, ...
```

### Strong
```text
Method D leads on both datasets, and its margin widens on the harder second one
(Table 2).
```

## Review Guidance
Some readers do skip figures, so restating one key number in the text is fine. Flag transcription only when the prose reproduces the artifact row by row.
